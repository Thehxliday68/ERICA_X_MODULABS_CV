# PRT（同行评审模板）
- [ ] **1. 是否已提交解决给定问题的完整代码？**
  - 检查问题所需的最终交付成果是否已附上。
  - 重要提示！请截取符合相关条件的部分并将其作为证据附上。

- [ ] **2. 阅读整段代码中最关键、最复杂或最难理解的部分后，是否能通过注释或文档字符串完全理解代码？**
  - 检查为什么该代码块被认为是关键代码块。
  - 检查代码块是否附有文档字符串或注释。
  - 检查是否描述了代码的功能、存在理由和运行原理。
  - 查看注释，确认是否能够理解代码。
  - 重要提示！请将您认为写得好的部分截取下来，作为证据附上。

- [ ] **3. 是否留下了通过调试解决错误的记录，或尝试了新的方法及其他实验？**
  - 检查问题原因和解决过程是否已正确记录。
  - 检查除项目评估标准外所做的其他尝试或实验是否已记录。
  - 重要提示！请将您认为写得好的部分截取下来，作为证据附上。

- [ ] **4. 是否认真写下了反思？**
  - 检查是否记录了已完成代码或项目交付物解决问题后的经验、需要改进的方面及感受。
  - 检查是否通过绘图说明整个代码执行流程，以帮助理解。
  - 重要提示！请将您认为写得好的部分截取下来，作为证据附上。

- [ ] **5. 代码是否简洁高效？**
  - 检查是否遵循 Python 风格指南（PEP 8）。
  - 检查是否通过函数化或模块化来减少代码重复并提升通用性。
  - 重要提示！请将您认为写得好的部分截取下来，作为证据附上。
